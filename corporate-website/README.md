# Sprinkle Industries Website

A professional, production-ready corporate website for Sprinkle Industries, LLC. Static HTML, CSS, and JavaScript — no framework dependencies, fast load times, and easy to deploy.

## Features

✅ **Responsive Design** – Mobile-first, works on all devices  
✅ **Fast & Lightweight** – Pure HTML/CSS/JS, no build step required  
✅ **SEO Optimized** – Structured metadata, sitemap, robots.txt  
✅ **Accessibility** – WCAG-compliant semantic HTML  
✅ **Dark Mode Support** – Automatically adapts to system preferences  
✅ **Professional Footer** – Legal business name, copyright, contact, policy links  
✅ **Contact Form** – Email integration for inquiries  

## Pages

- **Home** (`index.html`) – Hero section with service overview and CTA
- **About** (`about.html`) – Company mission and approach
- **Services** (`services.html`) – Detailed service offerings
- **Contact** (`contact.html`) – Contact form and direct email
- **Privacy Policy** (`privacy.html`) – Privacy policy
- **Terms of Service** (`terms.html`) – Terms and conditions
- **404** (`404.html`) – Error page

## Deployment

The website files are in the `corporate-website/` folder in the sms-crm repository. To deploy:

1. **GitHub Pages**: Push to main branch and enable Pages in repo settings
2. **Netlify**: Connect repo and deploy from this folder
3. **Vercel**: Import repo and specify this folder as root
4. **Self-hosted**: Copy files to your web server

## Customization

- Edit HTML files to change content
- Modify `styles.css` for design/colors
- Update contact email in footer and contact form
- Test locally: `python3 -m http.server 8000`

## Browser Support

- Chrome/Edge 90+
- Firefox 88+
- Safari 14+
- Mobile browsers (iOS Safari, Chrome Mobile)
